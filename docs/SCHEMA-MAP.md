# Schema map: Supabase (PostgreSQL) to MariaDB

Status: PLANNED. Built from a static replay of the 95 source migrations; **no live data or live schema was read**. Column names are what the migrations declare and may omit columns added by statements the replay did not parse (ASSUMPTION). Per your instruction there is no data migration: you move data yourself, so this map and `docs/IMPORT-TEMPLATE.md` (written with the R2 slice) are the contract.

## Type mapping

| PostgreSQL | MariaDB 11.4 | Note |
|---|---|---|
| uuid | `UUID` (native type) | Primary keys are generated by the API (UUIDv7) so imports keep their ids |
| timestamptz | `DATETIME(3)` stored in UTC | Convert to Europe/London only for display and for calendar-month arithmetic |
| jsonb | `JSON` (validated) | Indexed through generated columns where queried |
| text[] / arrays | child table or `JSON` | Decided per table |
| enum types | `VARCHAR` plus `CHECK` | Easier to migrate than MariaDB `ENUM` |
| numeric(p,s) | `DECIMAL(p,s)` | Money in pence as `INT` where it is an amount, to avoid rounding |
| boolean | `TINYINT(1)` |  |
| auth.users | none | Clerk holds identity. `users.clerk_user_id` links; `users.email` is the join key for first sign-in |
| RLS policy | `Authz` method | See `docs/AUTHORISATION-MAP.md` |
| SECURITY DEFINER function / trigger | PHP service inside a transaction | See the rules table in the authorisation map |

## New tables with no source equivalent

| Table | Why |
|---|---|
| `enquiries` | Contact form and course enquiries (replaces an email-only edge function) |
| `files` | Metadata for the private folder: id, owner, kind, size, sha256, stored name |
| `rate_limits` | Per-IP and per-key counters for public endpoints (verify, contact, feedback) |
| `schema_migrations` | Applied migration names and checksums |
| `outbox_email` | Emails queued by handlers and sent by cron, with status and retry count |
| `claims_log` (optional) | Not needed: the claim register is a file in the repo, checked at build time |
